# «Посчитай плитку» — пакет документации MVP

Версия пакета: **1.0**  
Назначение: передача в **Codex / Claude Code / Cloud Code** для поэтапной разработки.

## Что разрабатывается

«Посчитай плитку» — бесплатный одностраничный визуальный сервис для расчёта и раскладки керамической плитки и керамогранита.

Пользователь выбирает шаблон помещения или рисует простой план, добавляет проёмы и схематичные объекты, переключается между полом и стенами, назначает плитку на зоны, двигает раскладку и получает расчёт по материалам, подрезкам и коробкам.

## Главные решения

- Название продукта: **«Посчитай плитку»**.
- Интерфейс работает в пределах одного экрана на компьютере и телефоне.
- Основные действия выполняются через карточки, пресеты и клики. Ручной ввод нужен только для точных размеров.
- В MVP нет 3D, авторизации, базы данных, серверного API и каталога производителей.
- Рабочий редактор делается на React + TypeScript + Konva.
- SEO-страницы формируются как статический HTML. Сам редактор размещается по адресу `/app/`.
- Проект работает на обычном статическом или PHP-хостинге. Node.js нужен только локально для сборки.
- Реклама Vilray Studio и смежных проектов управляется из одного JSON-конфига.
- GEO в документах означает **Generative Engine Optimization**, то есть подготовку страниц для поисковых ответов и AI-систем. Региональные сигналы описаны отдельно.

## Что лежит в пакете

- `docs/` — продуктовые, UX, технические, SEO и проектные документы.
- `configs/` — примеры конфигов для размеров плитки, шаблонов помещений, рекламы, SEO и аналитики.
- `references/` — дизайн-система и скриншот сервиса «Сравни плитку».
- `sources/` — перечень официальных источников, на которых основана SEO/GEO-часть.

## Что нужно заполнить перед публикацией

В `configs/project-config.example.json` и `configs/ads-registry.example.json` заменить:

- финальный домен сервиса;
- URL Vilray Studio;
- URL «Сравни плитку»;
- URL «Плитку ПТФ»;
- ID Яндекс Метрики;
- ссылки на политику и контакты.

Спеллинг и URL основного бренда вынесены в конфиг. В документации по умолчанию используется **Vilray Studio**.
## Быстрый запуск разработки

После Этапа 0 в проекте появилась рабочая кодовая база приложения.

Команды:

```bash
npm install
npm run dev
npm run test
npm run build
```

Локальные адреса:

- главная SEO-страница: `http://127.0.0.1:5173/`
- редактор: `http://127.0.0.1:5173/app/`

Где менять основные данные:

- тексты и брендовые настройки: `configs/project-config.example.json`
- дизайн-токены: `configs/design-tokens.css`
- шаблоны помещений: `configs/room-templates.json`
- форматы плитки: `configs/tile-sizes.json`
- события аналитики: `configs/analytics-events.json`
- стартовые SEO-страницы: `content/seo/pages.json`
- каркас интерфейса редактора: `src/ui/App.tsx`

Сборка создаёт папку `dist/`. На обычный статический или PHP-хостинг загружается содержимое `dist/`.
