# Официальные источники для SEO/GEO-части

Документ фиксирует источники, которые нужно проверять при изменении SEO-архитектуры.

## Google Search Central

- Understand JavaScript SEO Basics.
- Fix Search-Related JavaScript Problems.
- SEO Starter Guide.
- Introduction to Structured Data Markup.
- AI Features and Your Website.
- Optimizing for Generative AI Features in Google Search.
- Creating Helpful, Reliable, People-First Content.
- Guidance on Generative AI Content.

Практический вывод для проекта:

- важный контент должен быть доступен поиску;
- статическая оболочка снижает зависимость от JavaScript-рендера;
- стандартные SEO-практики применяются и к AI-функциям поиска;
- отдельный `llms.txt` не требуется для присутствия в Google Search;
- массовые страницы без самостоятельной пользы не создавать.

## Яндекс Вебмастер

- Sitemap.
- Schema.org.
- JSON-LD.
- Structured Data Validator.
- Breadcrumbs.
- Organization information.
- Site quality and indexing guidance.

Практический вывод для проекта:

- sitemap должен быть доступен роботу;
- использовать только поддерживаемую и валидную разметку;
- размеченные данные должны совпадать с видимым содержимым;
- организационные и региональные данные должны быть реальными.

Перед крупным SEO-релизом проверить актуальные версии документов на официальных сайтах Google и Яндекса.
