# Модель данных

## 1. Общие правила

- все ID — строки UUID;
- размеры — целые миллиметры;
- площади вычисляются, а не хранятся как источник истины;
- формат проекта имеет `schemaVersion`;
- импорт проходит миграции и валидацию;
- UI-состояние не смешивается с данными проекта.

## 2. Project

```ts
interface TileProject {
  schemaVersion: number;
  id: string;
  name: string;
  createdAt: string;
  updatedAt: string;
  room: Room;
  surfaces: Surface[];
  objects: RoomObject[];
  materials: TileMaterial[];
  settings: ProjectSettings;
}
```

## 3. Room

```ts
interface Room {
  templateId: string | null;
  heightMm: number;
  contour: PointMm[];
}

interface PointMm {
  x: number;
  y: number;
}
```

## 4. Surface

```ts
interface Surface {
  id: string;
  type: 'floor' | 'wall' | 'box-front' | 'box-side' | 'custom';
  name: string;
  widthMm: number;
  heightMm: number;
  sourceRef: string | null;
  openings: Opening[];
  zones: FinishZone[];
  viewport: SurfaceViewport;
}
```

## 5. Opening

```ts
interface Opening {
  id: string;
  type: 'door' | 'window' | 'custom';
  xMm: number;
  yMm: number;
  widthMm: number;
  heightMm: number;
  sillHeightMm?: number;
}
```

## 6. RoomObject

```ts
interface RoomObject {
  id: string;
  presetId: string;
  label: string;
  xMm: number;
  yMm: number;
  widthMm: number;
  depthMm: number;
  rotation: 0 | 90 | 180 | 270;
  excludesFloorArea: boolean;
  createsSurfaces: boolean;
}
```

## 7. FinishZone

```ts
interface FinishZone {
  id: string;
  name: string;
  shape: RectZone | PolygonZone;
  materialId: string | null;
  layout: LayoutSettings;
  manualEdits: ManualTileEdit[];
}
```

MVP UI создаёт только прямоугольные зоны, но модель допускает ортогональный полигон для базовой зоны.

## 8. TileMaterial

```ts
interface TileMaterial {
  id: string;
  name: string;
  swatch: {
    type: 'color' | 'pattern';
    value: string;
  };
  widthMm: number;
  heightMm: number;
  piecesPerBox?: number;
  boxAreaM2?: number;
  reservePercent: number;
}
```

## 9. LayoutSettings

```ts
interface LayoutSettings {
  pattern: 'straight' | 'half-offset';
  rotation: 0 | 90;
  groutMm: number;
  originXmm: number;
  originYmm: number;
  originMode:
    | 'auto-best'
    | 'tile-center'
    | 'joint-center'
    | 'corner-tl'
    | 'corner-tr'
    | 'corner-bl'
    | 'corner-br'
    | 'manual';
  criticalCutMm: number;
}
```

Текущий дефолт для новых поверхностей: `corner-tl`. Режим `auto-best` остается в типе как будущий режим автоматического подбора.

## 10. ManualTileEdit

```ts
interface ManualTileEdit {
  tileKey: string;
  offsetXmm: number;
  offsetYmm: number;
  rotationDelta: 0 | 90;
  hidden: boolean;
  note?: string;
}
```

## 11. UI store

Отдельно хранить:

- текущий режим;
- выбранную поверхность;
- выбранную зону;
- выбранный объект;
- открытый bottom sheet;
- историю undo/redo;
- состояние сохранения;
- прогресс пересчёта;
- рекламные показы текущей сессии.

## 12. Версионирование

Первый формат: `schemaVersion: 1`.

Любое изменение экспортируемой структуры требует:

- миграции;
- теста старого файла;
- обновления документации;
- записи в CHANGELOG.
## Актуализация 2026-07-15 — несколько помещений и проёмы

- `room.contour` сохранён для совместимости и считается контуром первого помещения.
- `room.areas` хранит список помещений; старые проекты гидратируются как `room-1`.
- `room.openings` хранит двери и проходы, привязанные к `surfaceId`.
- `room.partitions` хранит внутренние ортогональные перегородки; каждая перегородка создаёт две стеновые поверхности.
- Поверхности получают стабильный `sourceRef`, чтобы материалы и зоны сохранялись после перестроения геометрии.
