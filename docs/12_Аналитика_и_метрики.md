# Аналитика и метрики

## 1. Принцип

Аналитика должна отвечать, дошёл ли пользователь от поиска до готового расчёта. Размеры помещения, названия проектов и содержимое экспортируемых файлов не отправляются.

## 2. Инструменты

MVP:

- Яндекс Метрика;
- Яндекс Вебмастер;
- Google Search Console;
- Google Analytics опционально.

ID и включение задаются через конфиг.

## 3. Основная воронка

1. `service_open`;
2. `template_selected`;
3. `surface_opened`;
4. `tile_format_selected`;
5. `layout_generated`;
6. `calculation_opened`;

## 5. Разрешённые параметры

- template ID;
- surface type;
- tile format preset ID;
- pattern type;
- device class;
- route/SEO page;
- placement ID;
- promoted project ID;
- error code;
- количество поверхностей в диапазоне, например `1`, `2-4`, `5+`.

## 6. Запрещённые параметры

- точные размеры помещения;
- пользовательские названия;
- импортированный JSON;
- координаты объектов;
- содержимое PDF;
- любые персональные данные.

## 7. Продуктовые метрики

- доля пользователей, выбравших шаблон;
- доля пользователей, открывших поверхность;
- доля построивших раскладку;
- доля открывших расчёт;
- доля завершивших экспорт;
- среднее число поверхностей на завершённый проект;
- использование автоматических вариантов;
- частота ручной настройки;
- клики на каждый проект экосистемы.

## 8. SEO-метрики

- показы и клики по странице;
- CTR;
- переход из SEO-страницы в редактор;
- завершённый расчёт по landing route;
- поисковые запросы по форматам и сценариям;
- индексирование и ошибки sitemap;
- брендовые запросы.

## 9. Ошибки

Коды ошибок должны быть стабильными:

- `ROOM_SELF_INTERSECTION`;
- `SURFACE_INVALID`;
- `OPENING_OUT_OF_BOUNDS`;
- `ZONE_OVERLAP`;
- `MATERIAL_MISSING`;
- `LAYOUT_TOO_DENSE`;
- `UNCOVERED_AREA`;
- `IMPORT_SCHEMA_INVALID`.

Текст пользователя не отправлять.
