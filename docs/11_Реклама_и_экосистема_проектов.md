# Реклама и экосистема проектов

## 1. Задача

Сервис бесплатный и рекламирует продукты Vilray после того, как пользователь получил полезный результат. Реклама не должна снижать доверие, перекрывать поле или мешать расчёту.

## 2. Проекты запуска

1. **Vilray Studio** — основной сайт и предложение разработки визуальных цифровых инструментов.
2. **Сравни плитку** — сервис визуального сравнения плитки в интерьерах.
3. **Плитку ПТФ** — смежный проект, URL и формулировка заполняются перед публикацией.
4. Будущие проекты — добавляются в реестр без изменения компонентов интерфейса.

Название, URL, UTM и тексты хранятся только в `configs/ads-registry.example.json`.

## 3. Основной рекламный сценарий

После формирования расчёта показать:

> Нужен такой калькулятор для вашего каталога или бренда?

Кнопка:

> Обсудить сервис с Vilray Studio

Это главный B2B-переход.

## 4. Места размещения

### Desktop

- компактная карточка внизу правой панели;
- карточка после таблицы расчёта;
- подпись в PDF;
- блок смежных инструментов под SEO-контентом.

### Mobile

- карточка после готового расчёта;
- раздел «Другие инструменты» в меню;
- подпись в PDF;
- без постоянного баннера над bottom navigation.

## 5. Контекстный выбор

- если пользователь ещё не рассчитал проект, показывать только мягкую подпись Vilray Studio;
- после расчёта показывать B2B-предложение Vilray Studio;
- при сценариях сравнения материалов показывать «Сравни плитку»;
- «Плитку ПТФ» показывать только в релевантных местах, заданных конфигом;
- будущий проект подключается через `tags` и `placements`.

## 6. Ограничение частоты

- одна основная рекламная карточка на экране;
- один показ конкретной карточки в конкретном месте за сессию, если пользователь её закрыл;
- никаких модальных окон при первом открытии;
- никаких автоматических переходов;
- рекламная ссылка открывается только по клику;
- скрытие карточки сохраняется в sessionStorage.

## 7. Визуальный стиль

Карточка выглядит как часть продуктовой линейки:

- белый или светло-сиреневый фон;
- тонкая граница;
- небольшой логотип;
- 1 заголовок;
- 1 строка пояснения;
- 1 кнопка;
- пометка «Проект Vilray» или «Другой инструмент».

Не использовать агрессивные цвета, таймеры и рекламные обещания.

## 8. Экспорт

В бесплатном PDF:

> Расчёт создан в сервисе «Посчитай плитку» — проект Vilray Studio.

PDF должен содержать спокойный водяной знак сервиса/студии. Реализуется на этапе «Расчёт и экспорт», не в этапе редактирования помещения.

Ниже допустима одна ссылка или QR-код на сервис. Реклама смежных проектов в PDF не нужна в MVP.

## 9. SEO-страницы

Внизу тематической страницы допускается блок из трёх карточек:

- «Посчитай плитку»;
- «Сравни плитку»;
- Vilray Studio.

«Плитку ПТФ» подключается четвёртой карточкой или заменяет одну из карточек по контексту. Не превращать блок в каталог рекламы.

## 10. UTM и аналитика

Каждый проект задаёт:

- `utm_source=poschitay_plitku`;
- `utm_medium=internal_promo`;
- `utm_campaign` по проекту;
- `utm_content` по placement.

События:

- `promo_impression`;
- `promo_click`;
- `promo_dismiss`.

Параметры:

- project ID;
- placement ID;
- текущий режим приложения;
- источник трафика верхнего уровня без персональных данных.

## 11. Feature flags

Рекламный модуль можно:

- отключить целиком;
- отключить отдельный проект;
- отключить placement;
- изменить приоритет;
- задать даты кампании;
- ограничить desktop/mobile.

Все изменения выполняются через конфиг, без правки компонентов.
