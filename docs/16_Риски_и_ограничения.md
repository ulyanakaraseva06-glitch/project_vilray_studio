# Риски и ограничения

| Риск | Последствие | Что сделать |
|---|---|---|
| Сервис превращается в CAD | долгий срок и непонятный интерфейс | держать один массовый сценарий и пресеты |
| Слишком много ручных полей | пользователь уходит до результата | карточки, дефолты, точный ввод по запросу |
| React SPA остаётся единственной страницей | слабая индексируемость | статические SEO-страницы и отдельный `/app/` |
| Расчёт обещает абсолютную точность | претензии и неверная закупка | консервативный расчёт и пояснение ограничений |
| Объединение обрезков даёт ошибки | заниженное количество | не оптимизировать повторное использование в MVP |
| Konva-сцена тормозит | плохой mobile UX | слои, упрощённый preview, лимит детализации |
| Много SEO-страниц без пользы | каннибализация и низкое качество | запуск 10–12 страниц, расширение по данным |
| Реклама мешает работе | падение доверия | показывать после ценности, без модалок |
| В конфиге неверные URL | битые переходы | build-валидация рекламного реестра |
| Аналитика собирает геометрию | риск приватности | whitelist параметров событий |
| Ручные правки ломаются после изменения зоны | неверный итог | сброс правок с предупреждением |
| Исходники и dist смешаны | ошибки публикации | отдельные архивы source/public |
| Плитка 60×120 записывается в разных единицах | ошибки расчёта | хранить только мм, форматировать в UI |
| Слишком ранний Web Worker/сложный state manager | лишняя сложность | добавлять только по измеренной проблеме |

## Не блокирующие вопросы перед публикацией

- финальный домен;
- буквальное название и URL основного сайта Vilray Studio;
- URL «Сравни плитку»;
- URL и описание «Плитку ПТФ»;
- ID Метрики;
- финальный логотип;
- текст политики конфиденциальности;
- контакт для B2B-заявки.

Все эти значения вынесены в конфиг и не должны блокировать разработку MVP.
