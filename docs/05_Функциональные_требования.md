# Функциональные требования

## 1. Проект

Пользователь может:

- начать новый проект;
- выбрать шаблон;
- импортировать JSON;
- автосохранять проект локально;
- вручную скачать файл проекта;
- сбросить текущую поверхность;
- сбросить весь проект после подтверждения;
- отменять и повторять действия.

## 2. Помещение

Шаблоны:

- прямоугольник;
- квадрат;
- узкий санузел;
- Г-образное помещение;
- помещение с выступом;
- своя форма.

Требования:

- только прямые стены и углы 90°;
- 4–12 стен;
- сторона 1–15 000 мм, вводится с точностью до 1 мм;
- высота 1 800–4 500 мм;
- контур замкнут и не самопересекается;
- размеры меняются кликом по размеру или карточкой пресета.

## 3. Поверхности

Из помещения автоматически формируются:

- пол;
- стены;
- поверхности коробов.

Каждая поверхность имеет:

- ширину и высоту;
- проёмы;
- список зон;
- текущий масштаб и положение;
- статус расчёта;
- предупреждения.

## 4. Двери и окна

Дверь добавляется кликом по стене. Пресеты ширины: 600, 700, 800, 900 мм. Пресеты высоты: 2000, 2100 мм.

Окно содержит:

- ширину;
- высоту;
- высоту подоконника;
- смещение от края.

Проёмы вычитаются из поверхности. Их нельзя вывести за пределы стены.

## 5. Схематичные объекты

Пресеты:

- ванна;
- душевой поддон;
- раковина;
- унитаз;
- стиральная машина;
- кухонный блок;
- шкаф;
- произвольный блок;
- короб.

Объект отображается как контур или полупрозрачный прямоугольник с подписью и размером. Реалистичные изображения не используются.

Мебель на плане служит ориентиром и не вычитается из площади пола, пока пользователь явно не включил настройку «не укладывать плитку под объектом».

## 6. Зоны

На каждой поверхности автоматически создаётся базовая зона на всю доступную площадь.

Пользователь может добавить:

- нижнюю часть стены;
- верхнюю часть стены;
- вертикальную полосу;
- горизонтальную полосу;
- душевую зону;
- фартук;
- прямоугольную произвольную зону.

Для зоны задаются:

- границы;
- приоритет слоя;
- материал;
- формат;
- шов;
- способ укладки;
- ориентация;
- origin раскладки;
- ручные правки.

Перекрытие зон должно быть либо запрещено, либо явно разрешено через порядок слоёв. Для MVP по умолчанию перекрытие запрещено.

## 7. Материалы

Материал создаётся без каталога брендов.

Параметры:

- название пользователя;
- цвет или условный образец;
- ширина;
- высота;
- толщина необязательна;
- плиток в коробке необязательно;
- площадь коробки необязательно;
- запас.

Популярные форматы хранятся в конфиге и показываются карточками.

## 8. Форматы MVP

Обязательные пресеты:

- 100×100;
- 200×200;
- 200×600;
- 200×900;
- 200×1200;
- 300×300;
- 300×600;
- 300×900;
- 400×1200;
- 600×600;
- 600×1200;
- 800×800;
- 800×1600;
- 1200×1200;
- свой размер.

В интерфейсе размеры показываются в сантиметрах: `60×120`.

## 9. Раскладка

MVP поддерживает:

- прямую сетку;
- смещение ряда на 1/2;
- поворот формата 0°/90°;
- общий шов;
- старт от центра поверхности;
- шов по центру;
- старт от выбранного угла;
- автоматический лучший вариант;
- перемещение origin по X/Y;
- точную подстройку кнопками 1, 5 и 10 мм.

После изменения параметра пересчёт выполняется автоматически с debounce. Во время drag показывается упрощённый preview.

## 10. Автоматические варианты

Пользователь видит до четырёх карточек:

- «Лучшие края»;
- «Меньше подрезок»;
- «Плитка по центру»;
- «Шов по центру».

Карточка показывает:

- мини-схему;
- минимальную подрезку;
- число резаных элементов;
- ориентировочный отход.

## 11. Ручная правка

По умолчанию скрыта в меню «Точная настройка».

Разрешено:

- сдвинуть отдельную плитку;
- повернуть на 90°;
- удалить элемент;
- вернуть элемент;
- пометить как целый/резаный только для визуального комментария, не меняя расчёт без подтверждения.

После изменения размера зоны ручные правки сбрасываются с предупреждением.

## 12. Расчёт

Сервис считает:

- полезную площадь поверхности;
- площадь каждой зоны;
- число целых плиток;
- число резаных элементов;
- эквивалентное количество плиток по площади использованных фрагментов;
- число физических заготовок по алгоритму MVP;
- отход;
- запас;
- коробки, если известна упаковка;
- итог по материалам;
- итог по поверхностям.

## 13. Экспорт

PNG:

- выбранная поверхность;
- все поверхности отдельными изображениями опционально;
- легенда материалов;
- размеры и номера поверхностей.

Печатный PDF:

- данные проекта;
- схема плана;
- схема каждой поверхности;
- таблица материалов;
- пояснение ограничений;
- небольшая подпись Vilray Studio.

JSON:

- версия формата;
- все геометрические данные;
- материалы;
- настройки;
- ручные правки;
- без изображений и персональных данных.

## 14. Помощь

Панель «Как работать» содержит пять шагов и короткие иллюстрации. Справка не должна блокировать использование сервиса.

## 15. Реклама

Рекламный модуль читает внешний конфиг и умеет:

- выбирать карточку по месту размещения;
- фильтровать по типу пользователя/сценарию без персональных данных;
- подставлять UTM;
- ограничивать частоту показа в рамках сессии;
- отправлять события показа и клика;
- отключаться feature flag.
