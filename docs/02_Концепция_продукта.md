# Концепция продукта «Посчитай плитку»

## 1. Формулировка

«Посчитай плитку» — бесплатный визуальный планировщик, который помогает разложить плитку по полу и стенам конкретного помещения, увидеть подрезки и рассчитать количество материала.

Сервис не должен ощущаться как CAD-программа. Он должен быть понятен розничному покупателю, менеджеру салона и плиточнику без обучения.

## 2. Главная пользовательская ценность

Пользователь получает не абстрактное число квадратных метров, а наглядный ответ:

- как плитка ляжет на конкретную поверхность;
- где будут целые элементы и подрезки;
- можно ли улучшить края смещением раскладки;
- сколько плиток и коробок потребуется;
- какие материалы используются на каждой зоне.

## 3. Главный принцип интерфейса

**Сначала выбор и визуальное действие, затем точный ввод.**

Пользователь по большей части:

- выбирает шаблон помещения;
- кликает по типовым размерам;
- выбирает дверь, окно или объект карточкой;
- выбирает поверхность;
- выбирает готовую зону;
- выбирает формат плитки;
- выбирает вариант раскладки.

Числа вводятся только там, где без них нельзя получить корректный расчёт.

## 4. Для кого

Основные группы:

- розничный покупатель перед покупкой плитки;
- менеджер салона или магазина;
- плиточник и замерщик;
- дизайнер интерьера;
- продавец или дилер отделочных материалов;
- производитель, который оценивает возможность брендированного инструмента.

## 5. Массовость

Сервис обязан давать первый визуальный результат не позднее чем после четырёх действий:

1. выбрать помещение;
2. выбрать типовой размер;
3. выбрать поверхность;
4. выбрать формат плитки.

После этого раскладка строится автоматически с дефолтным швом и понятным вариантом старта.

## 6. Позиционирование

Публичное название: **Посчитай плитку**  
Подзаголовок: **Визуальный расчёт и раскладка плитки онлайн**

Короткая формулировка:

> Нарисуйте помещение, разложите плитку на полу и стенах, проверьте подрезки и получите расчёт количества.

## 7. Что продукт даёт Vilray Studio

- органический трафик по расчёту и раскладке плитки;
- демонстрационный кейс цифрового инструмента;
- переходы на основной сайт студии;
- переходы на «Сравни плитку», «Плитку ПТФ» и будущие проекты;
- основу для white-label версии для производителя или дилера.

## 8. Модель монетизации MVP

Для конечного пользователя сервис бесплатный и работает без регистрации.

Коммерческая ценность создаётся через:

- ненавязчивую рекламу проектов Vilray;
- заявки на разработку брендированной версии;
- будущие интеграции с каталогами производителей;
- будущие платные функции для B2B, не входящие в MVP.

## 9. Критерий правильного продукта

Пользователь без инструкции должен понять, как:

- выбрать помещение;
- открыть пол или стену;
- назначить плитку;
- сдвинуть раскладку;
- открыть расчёт.

Если для базового действия требуется читать длинную справку, интерфейс спроектирован неправильно.
