# Мастер-промпт для Codex

Скопировать текст ниже в новый диалог Codex вместе с архивом документации.

---

Ты разрабатываешь MVP сервиса **«Посчитай плитку»**.

Сначала открой `README.md`, затем `docs/01_Карта_документов_для_Codex.md`. Прочитай документы этапа 0 в указанном порядке. Не начинай реализацию, пока не перечислишь, какие требования считаешь основными и какие файлы создашь на первом этапе.

Главная задача продукта: массовый пользователь без опыта в CAD выбирает помещение, поверхность, плитку и вариант раскладки, затем получает понятную схему и расчёт. Интерфейс должен работать в пределах одного экрана на desktop и mobile. Основные действия выполняются карточками и пресетами; ручной ввод используется только для точных размеров.

Обязательные ограничения:

- не добавлять 3D;
- не добавлять авторизацию, базу, API, Docker или серверный Node.js;
- не добавлять каталог производителей;
- не превращать интерфейс в пошаговый многостраничный мастер;
- не добавлять новую библиотеку без объяснения проблемы, которую она решает;
- не менять дизайн-систему;
- не усложнять ручную правку сверх требований MVP;
- не обещать абсолютную точность расчёта;
- не отправлять геометрию пользователя в аналитику.

Технологии:

- Vite;
- React;
- TypeScript;
- Konva/react-konva только для редактора;
- обычный CSS с токенами;
- Vitest;
- статические SEO-страницы, создаваемые build-скриптом;
- без серверной части после публикации.

Работай строго по этапам из `docs/14_Этапы_разработки_и_архивы.md`.

В конце каждого этапа:

1. дай список реализованного;
2. перечисли изменённые файлы;
3. дай команды запуска и тестирования;
4. подготовь рабочую сборку;
5. укажи известные ограничения;
6. подготовь архивы с понятными именами;
7. остановись и дождись проверки перед следующим этапом.

При конфликте документов используй приоритет из `README.md`. Специализированный документ важнее `docs/99_Полное_ТЗ_MVP.md`.

Начни с этапа 0. Сначала опиши план файлов и критерии готовности этапа, затем реализуй его.
