# Логика раскладки и расчёта

## 1. Единицы

Все внутренние размеры хранятся целыми числами в миллиметрах.

- помещение в UI: метры и сантиметры;
- плитка в UI: сантиметры;
- шов и подрезки: миллиметры;
- площади: квадратные метры с точностью до 0,01 м²;
- расчёт выполняется без округления размеров на промежуточных этапах.

## 2. Полезная геометрия поверхности

Полезная область зоны:

`полигон зоны − проёмы − исключённые области`.

Для стены проёмы вычитаются. Для пола мебель не вычитается по умолчанию. Объект с включённым флагом «не укладывать под объектом» создаёт прямоугольный вырез.

## 3. Шаг сетки

Для прямой укладки:

- шаг X = ширина плитки + ширина шва;
- шаг Y = высота плитки + ширина шва.

Шов не добавляется за внешней границей поверхности. Он учитывается между соседними плитками.

## 4. Генерация сетки

1. Определить bounding box зоны.
2. Расширить диапазон на один шаг за каждую сторону.
3. Сгенерировать прямоугольники плитки от `originX/originY`.
4. Для каждого элемента вычислить пересечение с полезным полигоном.
5. Исключить элементы без площади пересечения.
6. Классифицировать элемент.

## 5. Классификация

- **целая плитка**: площадь пересечения равна площади плитки с допуском;
- **подрезка**: пересечение меньше полной площади;
- **критическая подрезка**: минимальная ширина или высота видимого фрагмента меньше установленного порога;
- **микрофрагмент**: площадь меньше 3% площади плитки. Он считается ошибкой раскладки и подсвечивается.

Дефолтный порог критической подрезки: 80 мм. Пользователь может выбрать 50, 80, 100 или 150 мм.

## 6. Варианты origin

Для прямоугольной поверхности обязательные кандидаты:

- плитка по центру;
- шов по центру;
- левый нижний угол;
- правый нижний угол;
- левый верхний угол;
- правый верхний угол;
- найденные точки локального поиска с шагом 10 мм вокруг лучших кандидатов.

Для произвольной ортогональной зоны использовать bounding box и проверять итог по реальному полигону.

## 7. Оценка варианта

Для каждого кандидата вычислить:

- `minCut` — минимальный линейный размер подрезки;
- `criticalCuts` — количество критических подрезок;
- `cutTiles` — число резаных элементов;
- `wasteArea` — суммарная неиспользованная площадь заготовок;
- `symmetryPenalty` — отклонение крайних подрезок друг от друга;
- `microFragments` — число микрофрагментов.

Пример весов для общего score:

```text
score =
  minCut * 8
  - criticalCuts * 100000
  - microFragments * 1000000
  - cutTiles * 400
  - wasteAreaMm2 * 0.0002
  - symmetryPenalty * 8
```

Весы вынести в конфиг и покрыть тестами. В UI не показывать технический score.

## 8. Смещение на 1/2

Каждый второй ряд смещается на половину ширины плитки. Для повёрнутого формата смещение применяется по текущей горизонтальной стороне.

Отдельно проверять конфликт слишком короткой плитки и большой ширины шва.

## 9. Количество элементов

Нужно различать:

1. количество отображаемых элементов раскладки;
2. эквивалент по использованной площади;
3. количество плиток-заготовок, которое пользователь должен купить.

В MVP:

- каждая целая плитка требует одну заготовку;
- каждая независимая резаная плитка требует одну заготовку;
- автоматическое объединение двух подрезок в одну заготовку не выполняется;
- пользователь получает консервативный расчёт;
- это ограничение выводится рядом с итогом.

## 10. Расчёт материала

Для каждого материала:

- `layoutPieces = fullTiles + cutTiles`;
- `areaEquivalent = usedArea / tileArea`;
- `basePurchasePieces = layoutPieces`;
- `reservePieces = ceil(basePurchasePieces × reservePercent / 100)`;
- `purchasePieces = basePurchasePieces + reservePieces`.

Если пользователь отключает консервативный режим, можно показывать дополнительную справочную строку по площади, но не заменять основной результат.

## 11. Коробки

Если задано количество плиток в коробке:

`boxes = ceil(purchasePieces / piecesPerBox)`.

Если задана только площадь коробки:

`boxes = ceil((purchasePieces × tileAreaM2) / boxAreaM2)`.

Если заданы оба значения и они противоречат друг другу, показать предупреждение и использовать количество плиток в коробке.

## 12. Отход

Отход раскладки:

`wasteArea = sum(tileArea − intersectionArea)` для всех резаных элементов.

Процент отхода:

`wastePercent = wasteArea / totalBlankArea × 100`.

Запас пользователя не смешивать с отходом раскладки. В итогах показывать отдельно:

- отход по схеме;
- дополнительный запас;
- итог к покупке.

## 13. Несколько зон

Каждая зона рассчитывается независимо. Итоги объединяются по ID материала.

Не объединять обрезки между зонами и поверхностями. Это предотвращает ложную точность.

## 14. Ручные изменения

Ручная плитка хранит операцию поверх автоматически сгенерированной раскладки:

- offset;
- rotation;
- hidden;
- custom note.

Расчёт обязан учитывать фактическое пересечение изменённого элемента с зоной. Удалённый элемент не считается, но зона получает предупреждение о незакрытой области.

## 15. Проверка покрытия

После генерации вычислить:

- непокрытую площадь;
- двойное покрытие;
- выход элементов за разрешённую область.

Допуск на численные ошибки задаётся централизованно. При значимой непокрытой площади расчёт помечается как неполный.

## 16. Пояснение пользователю

Обязательный текст:

> Расчёт построен по введённым размерам и выбранной схеме. Перед покупкой проверьте размеры на объекте, параметры упаковки, калибр плитки, технологические зазоры и рекомендации производителя. Сервис не учитывает бой, дефекты партии и повторное использование обрезков между независимыми зонами.

## 17. Реализованный первый проход визуальной раскладки

Текущий первый проход раскладки работает только для прямоугольной стены:

- пользователь выбирает стену на рабочем поле;
- выбранный формат плитки назначается базовой зоне этой стены;
- сетка плитки строится в миллиметрах внутри прямоугольника стены;
- стартовая точка первого прохода — левый верхний угол поверхности;
- шаг сетки равен размеру плитки плюс шов;
- плитки обрезаются по границам стены;
- элементы классифицируются как целые, подрезки и критические подрезки;
- критическая подрезка по умолчанию — меньше 80 мм по ширине или высоте;
- сгенерированные плитки не сохраняются в проекте, а пересчитываются из материала, зоны и настроек раскладки.

Ограничения первого прохода:

- зоны пола и произвольные зоны пока не визуализируются раскладкой;
- автооптимизация origin пока не применяется;
- ручное смещение сетки и правка отдельных плиток остаются следующим этапом;
- PDF и закупочный расчет пока не используют визуальную сетку напрямую.

## 18. Реализованный второй проход раскладки

Второй проход расширяет раскладку на пол и делает сетку постоянной:

- выбранная поверхность хранится как `selectedSurfaceId`;
- пользователь может выбрать пол или конкретную стену;
- формат плитки назначается выбранной поверхности;
- если поверхность не выбрана, формат применяется как базовый материал проекта;
- раскладка пола строится по контуру помещения;
- для L-образных и других ортогональных помещений контур разбивается на прямоугольные ячейки, чтобы плитка не попадала в отсутствующие части помещения;
- раскладка неактивных поверхностей не исчезает, а приглушается;
- активная поверхность показывает подрезки заметнее.

Режимы старта раскладки в текущем проходе:

- `corner-tl` — старт от левого верхнего угла;
- `tile-center` — целая плитка по центру поверхности;
- `joint-center` — шов по центру поверхности.

Метрики текущего прохода:

- `edgeCuts` — минимальные крайние подрезки по сторонам;
- `minCutMm` — минимальная подрезка по поверхности;
- `criticalCount` — количество критических подрезок;
- `truncated` — сетка упрощена из-за лимита элементов.

Ограничения второго прохода:

- ручное перетаскивание сетки origin пока не реализовано;
- отдельные зоны внутри пола пока не редактируются;
- закупочный расчет и PDF будут подключаться позже к тем же данным раскладки.

## 19. Реализованный проход ручного origin

Раскладка выбранной поверхности поддерживает режимы старта:

- `corner-tl` — левый верхний угол;
- `corner-tr` — правый верхний угол;
- `corner-bl` — левый нижний угол;
- `corner-br` — правый нижний угол;
- `tile-center` — целая плитка по центру;
- `joint-center` — шов по центру;
- `manual` — ручное смещение через `originXmm/originYmm`.

Ручное смещение выполняется в миллиметрах. В интерфейсе основной шаг кнопок — 10 мм. При ручном смещении `originMode` становится `manual`. Сброс смещения возвращает старт к `corner-tl`.

Подписи подрезок показываются только на сторонах, где есть подрезка. Цвет подписей и рамок — фиолетовый из палитры сервиса.

## 20. Реализованный проход зон и первого расчёта

Раскладка теперь применяется не только к поверхности целиком, но и к выбранной зоне пола. Если зона выбрана, формат плитки, origin и ручное смещение меняют именно эту зону. Если зона не выбрана, изменения применяются к базовой зоне выбранной поверхности.

Добавлены дополнительные режимы старта:

- `corner-t`, `corner-l`, `corner-r`, `corner-b` — старт от середины стороны;
- угловые режимы остаются для диагональных стартов;
- `tile-center` и `joint-center` остаются отдельными режимами центрирования.

Первый расчёт строится из сгенерированной раскладки и группирует результат по материалам, поверхностям и зонам. Сгенерированные плитки не сохраняются в проекте. Резаные элементы считаются консервативно, без переноса обрезков между независимыми зонами.
## Актуализация 2026-07-15

- Раскладка применяется к базовой поверхности или к выбранной зоне поверхности.
- Дополнительные зоны считаются отдельными областями с собственным материалом, origin-режимом и смещением сетки.
- Расчёт v2 возвращает детализацию по зоне: площадь, полные плитки, подрезки, критичные подрезки, крайние подрезки, минимальную подрезку и признак усечения сетки.
- Если у материала задано количество плиток в коробке или площадь коробки, расчёт показывает ориентировочное количество коробок.
- На текущем этапе двери и проходы на стенах вычитаются из раскладки и расчёта; окна, мебель и сантехнические объекты остаются вне вычитаний.

## Актуализация 2026-07-15 — помещения, проёмы и edgeOffsets

- Для пользователя на холсте показываются `edgeOffsets`: если у стены/пола начинается целая плитка или шов, отображается `0 мм`.
- `edgeCuts` остаются расчётной метрикой подрезок и критичных подрезок.
- Двери и проходы на стенах передаются в раскладку как прямоугольные вырезы и вычитаются из площади расчёта.
- Добавлены паттерны укладки: без смещения, 1/2, 1/3, 1/4, «под дерево» и диагональ 45° в консервативном MVP-варианте.
- Несколько помещений считаются отдельными полами и наборами стен; перегородка создаёт две отдельные стеновые поверхности.
