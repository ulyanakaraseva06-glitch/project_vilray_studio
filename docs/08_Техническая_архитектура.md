# Техническая архитектура

## 1. Уровень сложности

**Статический многостраничный сайт + клиентское приложение со сборкой, без серверной части.**

Это позволяет одновременно получить:

- индексируемые SEO-страницы;
- сложный визуальный редактор;
- размещение на обычном хостинге;
- отсутствие базы, API и серверного Node.js.

## 2. Стек

Редактор:

- Vite;
- React;
- TypeScript;
- Konva + react-konva;
- обычный CSS;
- Lucide React;
- Vitest.

SEO-оболочка:

- статические HTML-страницы;
- JSON-контент в `content/seo/`;
- небольшой build-скрипт Node.js, который создаёт страницы перед сборкой;
- без SSR-сервера после публикации.

Не использовать:

- Next.js;
- Node.js как сервер;
- PHP API;
- базу данных;
- Docker;
- Redux;
- Tailwind;
- тяжёлый UI-kit;
- Three.js.

## 3. Почему Konva

Konva закрывает drag, pinch zoom, выделение, слои, большое число прямоугольников и экспорт PNG. Он используется только внутри редактора. Панели и SEO-страницы остаются обычным HTML/React/CSS.

## 4. Размещение

На хостинг загружается содержимое `dist/`.

Node.js требуется только локально или в CI:

- установить зависимости;
- запустить dev-сервер;
- сгенерировать SEO-страницы;
- собрать `dist`;
- выполнить тесты.

На сервере не нужны:

- PM2;
- база данных;
- cron;
- S3;
- Composer;
- Docker.

## 6. Маршруты

- `/` — главная SEO-страница с быстрым входом;
- `/app/` — редактор;
- тематические страницы — статические каталоги контента;
- параметры пресета передаются в `/app/` через query string;
- hash-routing не использовать.

Пример:

```text
/app/?room=bathroom-1700x2000&surface=wall&tile=600x1200
```

## 7. Хранение

- проект: localStorage;
- настройки интерфейса: localStorage;
- рекламная частота: sessionStorage;
- экспорт: JSON-файл;
- пользовательские данные на сервер не отправляются.

## 8. Undo/Redo

Использовать командную историю или сериализованные патчи. Не хранить полную тяжёлую сцену Konva. История ограничена 50–100 действиями.

## 9. Производительность

- геометрия и расчёт не зависят от React-компонентов;
- плитки рисуются внутри одного/нескольких Konva-слоёв;
- пересчёт после drag выполняется при завершении движения;
- preview во время движения упрощён;
- свыше 3000 элементов включается облегчённое отображение;
- расчёт можно вынести в Web Worker после подтверждённой необходимости, не в первом этапе;
- SEO-страницы не загружают Konva и редактор до клика по CTA.

## 10. Безопасность

- импорт JSON валидировать;
- запретить `eval`;
- пользовательский текст выводить через безопасные React-узлы;
- не принимать HTML от пользователя;
- не хранить секреты во фронтенде;
- ссылки рекламы проверять по конфигу сборки;
- политика CSP желательна после стабилизации внешних скриптов.

## 11. Сборка

```bash
npm install
npm run dev
npm run test
npm run build
npm run preview
```

Рекомендуемые scripts:

```json
{
  "prebuild": "node scripts/validate-content.mjs && node scripts/generate-seo-pages.mjs && node scripts/generate-sitemap.mjs",
  "build": "vite build",
  "test": "vitest run"
}
```

## 12. Что загружать

Публичный архив содержит только `dist/`.

Не загружать:

- `node_modules/`;
- `src/`;
- исходные документы;
- `.env`;
- тесты;
- временные файлы;
- экспортированные проекты пользователей.
