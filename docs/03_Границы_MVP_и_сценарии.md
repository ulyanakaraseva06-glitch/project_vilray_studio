# Границы MVP и пользовательские сценарии

## 1. Что входит в MVP

- один проект в браузере;
- работа без регистрации;
- шаблоны помещений и простое рисование ортогонального контура;
- автоматическое создание пола и стен;
- высота помещения;
- двери и окна;
- схематичные блоки мебели и сантехники;
- прямоугольный короб с дополнительными поверхностями;
- переключение между планом, полом, стенами и поверхностями короба;
- зоны отделки на поверхности;
- несколько материалов в одном проекте;
- популярные форматы плитки и собственный размер;
- прямой способ укладки и смещение на половину;
- поворот 0°/90°;
- ширина шва;
- автоматические варианты положения сетки;
- ручное перемещение всей раскладки;
- ограниченная ручная правка отдельного элемента;
- расчёт по поверхностям, зонам и материалам;
- запас и коробки;
- PNG, печатный PDF, экспорт/импорт JSON;
- локальное автосохранение;
- SEO/GEO-оболочка;
- аналитика без отправки размеров помещения;
- рекламные карточки экосистемы Vilray.

## 2. Что не входит

- 3D и фотореалистичный интерьер;
- личный кабинет и серверное сохранение;
- база данных;
- каталог реальных брендов;
- цены и смета работ;
- ёлочка, диагональ и сложные модульные схемы;
- криволинейные стены;
- сложные многоугольные вырезы;
- автоматическое повторное использование обрезков между зонами;
- профессиональная карта раскроя;
- совместная работа;
- мобильное приложение;
- CRM и формы заявок внутри расчётного процесса.

## 3. Сценарий A: розничный покупатель

1. Открывает сервис из поиска «расчёт плитки для ванной».
2. Выбирает шаблон ванной.
3. Выбирает типовой размер и высоту.
4. Добавляет дверь и ванну.
5. Открывает пол, выбирает 60×60.
6. Открывает стены, выбирает 60×120.
7. Смотрит подрезки и выбирает лучший вариант.
8. Получает общий расчёт и печатает PDF.

## 4. Сценарий B: менеджер салона

1. Быстро создаёт помещение клиента.
2. Назначает один формат на основную стену и другой на акцентную зону.
3. Показывает два варианта раскладки.
4. Формирует расчёт и отправляет изображение клиенту.
5. Видит ненавязчивую ссылку на «Сравни плитку» для дальнейшего сравнения коллекций.

## 5. Сценарий C: плиточник

1. Вводит точные размеры стены.
2. Добавляет дверной проём.
3. Сдвигает сетку по миллиметрам.
4. Проверяет размер крайних подрезок.
5. Получает ведомость по поверхности и предупреждение об ограничениях расчёта.

## 6. Сценарий D: несколько зон

1. Пользователь открывает стену.
2. Создаёт прямоугольную душевую зону.
3. Назначает зоне плитку 60×120 вертикально.
4. Основной части стены назначает 60×60.
5. Получает раздельный расчёт по двум материалам.

## 7. Сценарий E: мобильный телефон

1. Пользователь выбирает шаблон карточкой.
2. Рабочее поле остаётся видимым.
3. Настройки открываются снизу.
4. Масштабирование выполняется двумя пальцами.
5. Пользователь переключается между поверхностями горизонтальной каруселью.
6. Итог открывается как большая нижняя панель, а не как новая страница.

## 8. Дефолты, которые снижают ручной ввод

- типовой прямоугольник: 1700×2000 мм;
- высота: 2700 мм;
- шов: 2 мм;
- запас: 10%;
- раскладка: прямая;
- старт: лучший автоматический вариант;
- ориентация: по длинной стороне поверхности;
- упаковка: не задана, поле коробок скрыто до ввода данных.

## 9. Критерии успеха MVP

- первый результат строится без регистрации;
- стандартный сценарий проходит без инструкции;
- пользователь может сделать расчёт на экране 360 px шириной;
- значения расчёта воспроизводимы unit-тестами;
- статические SEO-страницы индексируются без выполнения JavaScript;
- реклама не перекрывает рабочее поле и не мешает расчёту.
