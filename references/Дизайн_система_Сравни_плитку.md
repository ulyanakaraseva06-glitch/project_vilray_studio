# Дизайн-схема «Сравни плитку»

Версия: 1.0  
Назначение: единая визуальная система для сервиса «Сравни плитку» и других сервисов Vilray Studio, связанных с плиткой, визуализацией, каталогами, презентациями, подборками и инструментами для менеджеров.

---

## 1. Суть визуального направления

Дизайн должен ощущаться как **профессиональный B2B SaaS-инструмент для визуальной продажи отделочных материалов**.

Ключевые ощущения:

- чисто;
- технологично;
- спокойно;
- визуально связано с интерьером и плиткой;
- без лишнего декора;
- больше похоже на рабочий интерфейс, чем на рекламный сайт;
- достаточно премиально, но не слишком дорого и холодно.

Главный принцип: **интерфейс не должен спорить с изображениями плитки и интерьеров**. Он должен помогать смотреть, сравнивать, выбирать и сохранять.

---

## 2. Где применять эту дизайн-схему

Подходит для:

- сервиса «Сравни плитку»;
- лендинга «Сравни плитку»;
- личного кабинета пользователя;
- админ-панели;
- сервиса генерации PDF-каталогов;
- сервиса подборок плитки;
- внутренних CRM/дашбордов для продаж плитки;
- презентационных мини-сайтов для производителей плитки;
- B2B-сервисов Vilray Studio для отделочных материалов.

Не стоит применять без адаптации для:

- люксовых имиджевых сайтов;
- ярких B2C-промо;
- детских/игровых интерфейсов;
- сайтов, где нужна эмоциональная, а не инструментальная подача.

## 3. Базовая цветовая логика

В основе — **белый интерфейс + светло-серый/бежевый фон + сиреневый акцент**.

Сиреневый акцент даёт узнаваемость сервиса. Бежевые оттенки связывают интерфейс с интерьером, плиткой, ремонтом и визуализациями.

| Назначение | HEX | Использование |
|---|---:|---|

Писать коротко, прикладно и коммерчески ясно.

- “Сравните плитку в одном интерьере”
- “Покажите клиенту вариант за несколько секунд”
- “Готовые изображения для мессенджера и презентации”

- “Инновационная платформа нового поколения”
- “Уникальная экосистема цифровой трансформации”
- “Невероятный пользовательский опыт”

- слева/по центру — изображение интерьера;
- справа — каталог плитки;
- снизу — сценарии/комнаты;
- активные элементы выделяются сиреневым.

Внешний вид:

- тёмная или светлая панель вокруг рендера допустима;
- карточки плитки — компактные;
- визуализатор не должен быть перегружен текстом;
- кнопки действий — маленькие, но читаемые.

## 16. Админка и личный кабинет

Админка и кабинет должны быть функциональными, без “маркетинговой красоты”.

Основные элементы:

- topbar;
- панели;
- таблицы;
- вкладки;
- бейджи статусов;
- карточки статистики.

Стиль:

- белые панели;
- фон `#F4F4F6`;
- заголовки 20–24 px;
- таблицы компактные;
- активные вкладки сиреневые.

---

## 17. Логика фонов

Для большинства сервисов Vilray Studio использовать такую схему:

1. Основной фон сайта/сервиса — `#FFFFFF` или `#F4F4F6`.
2. Интерьерные/маркетинговые секции — `#F7F2EA`.
3. Акцентные информационные блоки — `#F2EBF9`.
4. Сильные CTA/видео-блоки — тёмный фон `#18181E` или градиент `#18181E → #2A2436`.

Важно: сиреневый акцент не должен заливать всю страницу. Он должен работать точечно.

---

## 18. Иллюстрации и изображения

Для сервисов по плитке и интерьеру использовать:

- интерфейсные мокапы;
- скриншоты сервиса;
- интерьерные сцены;
- карточки плитки;
- изображения “до/после”;
- сравнение в одном интерьере;
- мобильные мокапы.

Не использовать:

- абстрактные 3D-иконки без смысла;
- слишком яркие градиенты;
- случайные stock-фото людей;
- перегруженные коллажи;
- интерьеры, где плитка плохо видна.

## 19. Адаптивность

### Desktop

- максимальная ширина контента 1200–1360 px;
- hero в 2 колонки;
- тарифы 4–5 карточек в ряд;
- видео-блок 2 колонки;
- много CTA, но без хаоса.

### Tablet

- hero можно оставить в 2 колонки, если хватает ширины;
- тарифы 2 колонки;
- карточки преимуществ 2–3 колонки.

### Mobile

- один столбец;
- CTA сразу под заголовком;
- кнопка “Войти” не должна теряться;
- можно использовать sticky bottom CTA;
- видео-блок должен идти рано, не в самом низу;
- карточки тарифов — вертикально.

## 21. Правила для новых сервисов Vilray Studio

При создании нового сервиса на этой дизайн-схеме:

1. Сначала определить главный сценарий пользователя.
2. Первый экран строить вокруг интерфейса, а не вокруг абстрактной картинки.
3. Использовать белый фон как базу.
4. Сиреневый использовать только для действий и активных элементов.
5. Бежевые секции использовать там, где нужно связать сервис с интерьером, материалами, каталогами.
6. Не делать перегруженные декоративные фоны.
7. Все карточки, кнопки, формы и таблицы держать в одной системе радиусов и границ.
8. CTA повторять после ключевых блоков.
9. Для B2B-сервисов обязательно показывать тарифы, сценарии применения и понятный следующий шаг.
10. Если есть внутренний интерфейс — обязательно показывать его на лендинге.

## 22. Короткий промпт для дизайнера или AI-дизайна

Светлый B2B SaaS-интерфейс для сервиса Vilray Studio в сфере плитки, интерьеров и визуализации. Белый фон, светло-серые и тёплые бежевые секции, сиреневый акцент `#A385C4`, шрифт Manrope, скругления 8–12 px, тонкие границы, мягкие тени, чистые карточки, интерфейсные мокапы, крупные CTA-кнопки, аккуратные line icons. Стиль должен выглядеть как рабочий digital-инструмент для менеджеров и производителей отделочных материалов: профессионально, спокойно, технологично, без лишнего декора.

## 23. Мини-чеклист качества

Перед сдачей дизайна проверить:

- [ ] Используется Manrope.
- [ ] Основной фон белый или очень светлый.
- [ ] Сиреневый акцент применён точечно, а не везде.
- [ ] Карточки имеют тонкие границы и радиус 12 px.
- [ ] CTA-кнопки хорошо видны.
- [ ] Есть чёткая иерархия H1/H2/H3.
- [ ] Интерфейсные мокапы выглядят как часть продукта.
- [ ] Иконки в одном стиле.
- [ ] На мобильной версии кнопки не теряются.
- [ ] Дизайн не спорит с интерьерными изображениями.
- [ ] Визуально понятно, что это рабочий сервис, а не просто презентация.
